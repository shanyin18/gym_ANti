# Gym ANti - 项目启动与访问指南

本文档汇总了前后端及监控系统的启动方式和访问地址。

---

## 🚀 快速启动命令

请在三个独立的终端窗口中分别运行以下命令：

### 1. 后端服务 (FastAPI)
```powershell
cd server-python
conda run --no-capture-output -n fastapi_env uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### 2. 前端页面 (React/Vue)
```powershell
npm run dev
```

### 3. 监控系统 (Prometheus + Grafana)
```powershell
docker-compose -f docker-compose.monitoring.yml up -d
```

*(停止监控系统：`docker-compose -f docker-compose.monitoring.yml down`)*

## 📊 常见问题

1.  **Grafana 看不到数据？**
    *   确保后端 `uvicorn` 已启动。
    *   在 Grafana 右上角时间范围选择 **"Last 5 minutes"**。
    *   去前端页面发几条消息产生流量。

2.  **Grafana 提示 "Dashboard not found"？**
    *   请手动导入根目录下的 `dashboard.json` 文件。

3.  **端口冲突？**
    *   如果 `3000` 端口被占用，前端可能会自动切到 `5174` 或其他端口，请以此类推。
