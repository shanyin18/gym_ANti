# 变更日志 - Grafana 可视化集成

**日期：** 2026-02-11
**变更类型：** 新功能 (Feature) / 可视化 (Visualization)
**作者：** Gemini Agent

---

## 1. 变更背景与目标

在完成了 Prometheus 指标采集后，虽然 `/metrics` 端点已经可以访问，但原始数据难以阅读。
本次变更的目标是引入 **Grafana**，配合 **Prometheus** 服务，搭建一套完整的监控大屏，实现：
1.  **数据采集**：启动 Prometheus 服务，定时抓取后端 `/metrics` 数据。
2.  **数据可视化**：启动 Grafana 服务，连接 Prometheus 数据源，展示图形化仪表盘。
3.  **容器化部署**：使用 Docker Compose 一键启动，保证环境一致性。

---

## 2. 实现逻辑

采用了 **Docker Compose** 编排方案，包含两个核心容器：

1.  **`gym_prometheus` (Prometheus)**：
    *   **配置**：通过挂载 `prometheus.yml` 配置文件，定义抓取任务。
    *   **网络**：使用 `host.docker.internal` 访问宿主机上的 FastAPI 服务（端口 8000）。
    *   **存储**：使用 Docker Volume 持久化存储监控数据。

2.  **`gym_grafana` (Grafana)**：
    *   **端口**：映射到宿主机 `3001` 端口（避免与前端开发服 3000 冲突）。
    *   **依赖**：依赖 Prometheus 容器启动。
    *   **存储**：使用 Docker Volume 持久化配置（如数据源、仪表盘）。

---

## 3. 代码变更对比

本次变更为 **新增文件**，不涉及现有代码修改。

### 3.1 Prometheus 配置文件 (`prometheus.yml`)

```yaml
# [NEW] 定义抓取规则
global:
  scrape_interval: 15s      # 每 15 秒抓取一次

scrape_configs:
  - job_name: "fastapi"
    metrics_path: "/metrics"
    static_configs:
      # host.docker.internal 指向宿主机，即 FastAPI 运行的地方
      - targets: ["host.docker.internal:8000"]
        labels:
          app: "gym_anti"
```

### 3.2 Docker Compose编排文件 (`docker-compose.monitoring.yml`)

```yaml
# [NEW] 定义服务栈
version: "3.8"

services:
  prometheus:
    image: prom/prometheus:v2.45.0
    container_name: gym_prometheus
    ports:
      - "9090:9090"
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml
      - prometheus_data:/prometheus
    # 允许容器访问宿主机网络
    extra_hosts:
      - "host.docker.internal:host-gateway"

  grafana:
    image: grafana/grafana:10.0.0
    container_name: gym_grafana
    ports:
      - "3001:3000"  # 映射到 3001
    depends_on:
      - prometheus

volumes:
  prometheus_data:
  grafana_data:
```

## 4. 验证与使用

1.  **启动服务**：
    ```bash
    docker-compose -f docker-compose.monitoring.yml up -d
    ```

2.  **访问地址**：
    *   Prometheus: `http://localhost:9090/targets` (检查 Target 状态是否为 UP)
    *   Grafana: `http://localhost:3001` (账号/密码: admin/admin)

3.  **配置仪表盘**：
    *   添加数据源：选择 Prometheus，URL 填 `http://prometheus:9090`
    *   导入仪表盘：推荐使用 ID `10574` 或 `3662`
